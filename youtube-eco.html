youtube-eco 개인정보처리방침

시행일: 2026년 10월 26일

youtube-eco(이하 "앱")는 운영자가 직접 소유한 YouTube 채널에 동영상을 예약 업로드하고, 제목·설명·썸네일을 관리하기 위해 개인적으로 사용하는 도구입니다. 일반 사용자에게 공개·판매되는 서비스가 아닙니다.

1. 이용하는 정보

앱은 Google OAuth를 통해 운영자 본인의 YouTube 계정에 대한 접근 권한(동영상 업로드·수정, 채널 정보 조회)만 사용합니다. 다른 사람의 개인정보는 수집하지 않습니다.

2. 이용 목적

운영자 채널의 동영상 업로드, 공개 예약, 제목·설명·태그·썸네일 수정, 재생목록 관리에만 사용합니다.

3. 보관 및 보호

OAuth 인증 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자에게 제공하지 않습니다.

4. 제3자 제공

수집한 정보를 판매하거나 제3자와 공유하지 않습니다. 데이터 처리는 Google(YouTube Data API)을 통해서만 이루어집니다.

5. Google API 정책 준수

앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 사용과 관련해서는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

6. 권한 철회

언제든지 Google 계정 > 보안 > 서드파티 액세스에서 앱의 접근 권한을 철회할 수 있습니다.
